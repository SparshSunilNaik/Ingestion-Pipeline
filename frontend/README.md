# Ingestion-Pipeline frontend

Next.js (App Router) workspace for the Ingestion-Pipeline backend.

```bash
npm install
npm run dev        # http://localhost:3000
```

The API base URL defaults to `http://127.0.0.1:8000`; override with `NEXT_PUBLIC_API_BASE`.
See the repository root `README.md` and `docs/WINDOWS_SETUP.md` for full setup.
